# Self Study Platform

Платформа для самообучения студентов с возможностью создания курсов, уроков и тестирования знаний.

## Описание проекта

Self Study Platform — это веб-приложение на Django Rest Framework, предоставляющее API для онлайн-обучения. Платформа позволяет преподавателям создавать курсы и уроки, добавлять тесты с вопросами, а студентам — просматривать материалы и проверять свои знания.

## Технологии

- **Python** 3.14
- **Django** 6.0
- **Django Rest Framework** 3.17
- **PostgreSQL**
- **Simple JWT** (аутентификация)
- **drf-yasg** (Swagger документация)
- **Poetry** (управление зависимостями)

## Функционал

- 🔐 JWT аутентификация (регистрация, вход, обновление токена)
- 👥 Ролевая модель: администратор, преподаватель, студент
- 📚 CRUD для курсов и уроков
- 📝 Тестирование знаний (создание тестов, вопросов, проверка ответов)
- 📊 Просмотр результатов тестирования
- 🔍 Поиск и фильтрация
- 📖 Swagger/ReDoc документация
- 🛠 Административная панель Django



## Роли пользователей

| Роль | Права |
|------|-------|
| **Администратор** | Полный доступ ко всем курсам, урокам, тестам и результатам |
| **Преподаватель** | Создание и управление своими курсами, уроками и тестами. Просмотр результатов своих тестов |
| **Студент** | Просмотр опубликованных курсов и уроков. Прохождение тестов. Просмотр своих результатов |



## API Endpoints

### Аутентификация
| Метод | URL | Описание | Доступ |
|-------|-----|----------|--------|
| POST | `/api/auth/token/` | Получить JWT токен | Все |
| POST | `/api/auth/token/refresh/` | Обновить токен | Все |
| POST | `/api/auth/register/` | Регистрация | Все |
| GET | `/api/auth/profile/` | Профиль пользователя | Авторизованные |

### Курсы
| Метод | URL | Описание | Доступ |
|-------|-----|----------|--------|
| GET | `/api/courses/` | Список курсов | Авторизованные |
| POST | `/api/courses/` | Создать курс | Учитель/Админ |
| GET | `/api/courses/{id}/` | Детали курса | Авторизованные |
| PUT/PATCH | `/api/courses/{id}/` | Обновить курс | Владелец/Админ |
| DELETE | `/api/courses/{id}/` | Удалить курс | Владелец/Админ |
| GET | `/api/courses/{id}/lessons/` | Уроки курса | Авторизованные |

### Уроки
| Метод | URL | Описание | Доступ |
|-------|-----|----------|--------|
| GET | `/api/lessons/` | Список уроков | Авторизованные |
| POST | `/api/lessons/` | Создать урок | Учитель/Админ |
| GET | `/api/lessons/{id}/` | Детали урока | Авторизованные |
| PUT/PATCH | `/api/lessons/{id}/` | Обновить урок | Владелец/Админ |
| DELETE | `/api/lessons/{id}/` | Удалить урок | Владелец/Админ |
| POST | `/api/lessons/{id}/add_test/` | Добавить тест | Учитель/Админ |

### Тесты
| Метод | URL | Описание | Доступ |
|-------|-----|----------|--------|
| GET | `/api/tests/` | Список тестов | Авторизованные |
| POST | `/api/tests/` | Создать тест | Учитель/Админ |
| GET | `/api/tests/{id}/` | Детали теста | Авторизованные |
| POST | `/api/tests/{id}/add_question/` | Добавить вопрос | Учитель/Админ |
| POST | `/api/tests/{id}/submit_answers/` | Отправить ответы | Студент |

### Результаты
| Метод | URL | Описание | Доступ |
|-------|-----|----------|--------|
| GET | `/api/results/` | Все результаты | Админ/Учитель |
| GET | `/api/results/{id}/` | Детали результата | Владелец/Учитель/Админ |
| GET | `/api/results/my_stats/` | Моя статистика | Авторизованные |

## Переменные окружения

Создайте файл `.env` в корне проекта на основе `.env.sample`:

| Переменная | Описание | По умолчанию |
|-----------|----------|-------------|
| `SECRET_KEY` | Секретный ключ Django | - |
| `DEBUG` | Режим отладки (True/False) | `False` |
| `DB_NAME` | Название базы данных | `self_study_project` |
| `DB_USER` | Пользователь PostgreSQL | `postgres` |
| `DB_PASSWORD` | Пароль PostgreSQL | - |
| `DB_HOST` | Хост базы данных | `localhost` |
| `DB_PORT` | Порт базы данных | `5432` |
| `ALLOWED_HOSTS` | Разрешенные хосты | `localhost,127.0.0.1` |

Пример `.env` файла:

```env
SECRET_KEY=django-insecure-ваш-секретный-ключ
DEBUG=True
DB_NAME=self_study_project
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
ALLOWED_HOSTS=localhost,127.0.0.1
